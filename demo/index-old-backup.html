Powerful Features

Everything you need for realistic physics-based UI interactions

🎯

Advanced Physics

Verlet integration with air resistance, friction, and collision detection. Papers bounce off boundaries with realistic damping and ground friction.

💨

Wind & Forces

Add dynamic wind oscillation with configurable strength and frequency. Create realistic environmental effects that respond to user interaction.

✂️

Tear Mechanics

Constraints break when stretched beyond threshold, creating realistic tearing effects. Papers can be torn apart and repaired programmatically.

🖱️

Smart Interactions

Hover effects gently repel particles. Drag with momentum for natural feel. Full mouse and touch support with multi-touch ready.

🎛️

Real-time Control

Update physics parameters on-the-fly. Toggle effects, adjust gravity, modify stiffness - all without recreating instances.

Get started with just a few lines of code

Basic Usage
Advanced
API
// Install
npm install soft-paper-ui

// Import
import { SoftPaper } from 'soft-paper-ui';

// Create soft paper effect
const paper = new SoftPaper('#myElement', {
  gravity: 0.18,
  stiffness: 0.85,
  interactive: true,
  shadow: true
});

// That's it! Your element now has physics 🎉
// Advanced configuration
const paper = new SoftPaper('#element', {
  // Grid resolution
  grid: { cols: 10, rows: 20 },
  
  // Physics parameters
  gravity: 0.18,
  stiffness: 0.85,
  damping: 0.92,
  airResistance: 0.995,
  friction: 0.98,
  iterations: 6,
  
  // Tear mechanics
  tearThreshold: 3.0,  // 3x rest length
  
  // Effects
  wind: true,
  windStrength: 0.05,
  windFrequency: 0.02,
  hoverEffect: true,
  hoverRadius: 80,
  
  // Interaction
  interactive: true,
  dragRadius: 50,
  boundaries: true
});

// Dynamic updates
paper.updateConfig({ gravity: 0.3 });
paper.setWind(true);
paper.repairTears();
// API Methods

// Start/stop animation
paper.start();
paper.stop();

// Update physics in real-time
paper.updateConfig({
  gravity: 0.25,
  stiffness: 0.9,
  damping: 0.95
});

// Wind control
paper.setWind(true);
const isWindy = paper.isWindEnabled();

// Tear mechanics
const tornCount = paper.getTornCount();
paper.repairTears();

// Get current config
const config = paper.getConfig();

// Cleanup
paper.destroy();  // Removes canvas, restores element
