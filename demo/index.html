Simple to Use

One line of code gets you ultra-smooth physics. Customize everything or use sensible defaults.

Basic Usage

Water-like cloth with punch effect - instant magic!

import { SoftPaper } from 'soft-paper-ui'; // That's it! Click to punch and watch it flow const paper = new SoftPaper('#my-element'); // Ripples spread on click, flows with gravity!

Custom Physics

Fine-tune the water-like cloth flow

const paper = new SoftPaper('#element', { // Natural cloth physics (like CodePen classic) gravity: 0.4, // Natural gravity stiffness: 0.98, // High stiffness damping: 0.99, // Natural damping tearThreshold: 3.5, // Tears at 3.5x iterations: 8, // Balanced solve // Interaction dragRadius: 30, // Direct grab interactive: true, // Click & drag boundaries: false // No walls }); // Click creates automatic punch ripple! // Ripples spread 150px with quadratic falloff

Advanced Features

Revert animations, ripples, waves, and more

// Revert to original position await paper.revertToOriginal(2000, 'elastic'); // Create ripple effect paper.createRipple(x, y, strength, radius); // Wave animation paper.createWave('horizontal', 8, 0.5); // Shake effect paper.shake(5, 600);
