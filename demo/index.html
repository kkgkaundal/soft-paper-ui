Features

✅ Pure 2D Canvas + Verlet integration (no external physics libraries)

✅ Extremely low CPU usage (<5% on modern devices)

✅ Mouse and touch interaction support

✅ Configurable physics parameters

✅ Optional wind oscillation effect

✅ ESM + UMD build for maximum compatibility

Usage

npm install soft-paper-ui
import { SoftPaper } from 'soft-paper-ui';
new SoftPaper('#element', { gravity: 0.18, stiffness: 0.85 });
